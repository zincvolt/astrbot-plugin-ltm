# astrbot-plugin-ltm

QQ 群聊的长期记忆插件，用于 [AstrBot](https://github.com/AstrBotDevs/AstrBot)。

它让机器人能"记住"跨会话的稳定事实：每轮回复后从对话里抽取值得记的内容，存成带向量的记忆；下次请求前按当前消息语义召回最相关的几条，注入 system prompt。

## 功能

- **记忆抽取**：回复后异步从 `用户话 + 机器人回复` 中抽取稳定事实（人物、偏好、约定等），写入 SQLite + 向量库。
- **语义召回**：`on_llm_request` 钩子按当前消息向量检索相关记忆（默认取最相关的若干条）注入上下文。
- **后台扫描**：定时任务批量处理积压的新群消息。
- **第三方模式适配**：会检测当前是否处于第三方 API 模式，跳过依赖本地服务的抽取路径。
- **管理命令**：`/记忆` 查看当前用户记忆，`/忘记 [关键词]` 删除记忆。

## 存储

记忆库是运行数据（SQLite `memory.db` + 向量），**不随代码发布**，需运行时由插件自建。数据目录可通过环境变量 `QQNTBOT_DATA` 指定，默认是本项目的数据目录。

## 依赖

- AstrBot 4.28+
- OpenAI 兼容的 embedding 服务（本机 8097）
- 一个 OpenAI 兼容的 chat 服务用于抽取（第三方模式下走对应 API）
- `httpx`

> 本插件只调用本机已运行的模型服务，不负责部署模型本身。
